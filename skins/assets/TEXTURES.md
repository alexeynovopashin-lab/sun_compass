# Библиотека текстур

Спецификация для файлов, которые кладутся в `skins/assets/textures/`. Цель — чтобы готовая
текстура заработала без подгонки: код скина уже знает, чего ожидать по размеру, формату
и способу наложения.

## Где живут и как грузятся

Текстуры лежат рядом со скинами на том же GitHub Pages — отдельного сервера не нужно,
он уже есть. Правило то же, что и для самих скинов: **грузится только то, что открыто**.
Общая сборка (`index.html`) текстур не касается вообще; скин подключает свои через
`<link rel="preload">` или в фоновом `background-image` — то есть только когда пользователь
уже открыл именно этот скин.

Из этого следует единственное жёсткое ограничение: **вес одного файла до 200 КБ**, у альфа-PNG
с царапинами и кляксами — до 400 КБ. Это всё ещё в разы легче фотографии, потому что почти все
текстуры ниже — бесшовные плитки маленького размера, растянутые CSS, а не полноэкранные картинки.

## Общее для всех текстур

- **Формат:** WebP для непрозрачных (шлифованный металл, латунь, пергамент) — на 25–35 % легче
  PNG при том же качестве, поддерживается везде, куда мы целимся. **PNG только там, где нужна
  альфа** (царапины, кляксы, потёртости) — WebP с альфой на iOS Safari местами барахлит,
  рисковать не стоит.
- **Профиль:** sRGB. Ничего другого браузер всё равно не уважает.
- **Плитки бесшовные.** Проверка простая: положить квадрат 2×2 из копий текстуры и посмотреть,
  виден ли шов на стыке. Photoshop → Filter → Other → Offset на половину размера в обе стороны
  покажет ровно эти стыки для правки.
- **Без запечённого света.** Никаких грradientов освещения, бликов от одной лампы, теней
  в одну сторону — это добавляет CSS-слой скина (`box-shadow`, `radial-gradient`), одинаково
  для любого поворота элемента. Текстура — только фактура поверхности.
- **Серый нейтральный, а не белый.** Середина тонового диапазона (RGB ~128,128,128) должна
  соответствовать «нейтрально», иначе `mix-blend-mode: overlay` будет систематически темнить
  или высветлять то, на что текстура ляжет.

## Спецификация по типам

### Шлифованный металл — линейный

Для прямых плоскостей: панель Braun, корпус синтезатора, обшивка марсохода.

| Параметр | Значение |
|---|---|
| Размер | 512×512, бесшовная плитка |
| Формат | WebP, без альфы |
| Тон | Градации серого, нейтральная середина |
| Контраст | Низкий-средний — риски должны читаться вблизи и пропадать в общем виде |
| Направление | Штрихи строго горизонтальные или строго вертикальные (не под углом — угол зададут через CSS `transform` там, где нужно) |
| Имя файла | `metal-brushed-linear.webp` |

### Шлифованный металл — радиальный

Для круглых элементов: циферблаты, кнопки, крутилки.

| Параметр | Значение |
|---|---|
| Размер | 1024×1024, **не бесшовная** — это готовый диск, а не плитка |
| Формат | WebP, без альфы |
| Тон | Как у линейного |
| Рисунок | Штрихи расходятся из геометрического центра квадрата, как заводская шлифовка на кнопке |
| Имя файла | `metal-brushed-radial.webp` |

### Алюминий

Более гладкий и холодный, чем сталь: кнопки, ободки, авиационные панели.

| Параметр | Значение |
|---|---|
| Размер | 512×512, бесшовная плитка |
| Формат | WebP, без альфы |
| Тон | Светлее и холоднее стали, минимальный шум |
| Имя файла | `metal-aluminum.webp` |

### Латунь

Тёплая, для викторианской и морской группы: хронометр, дальномер, штурманский прибор.

| Параметр | Значение |
|---|---|
| Размер | 512×512, бесшовная плитка |
| Формат | WebP, без альфы |
| Тон | Тёплый жёлто-серый в нейтральной середине — цвет самой латуни добавит CSS (`overlay` поверх `#b08d57`-подобной заливки), текстура даёт только фактуру |
| Вариант | Если удобно — версия с лёгкой патиной отдельным файлом `metal-brass-patina.webp` |
| Имя файла | `metal-brass.webp` |

### Пергамент

Карта проказников, алхимик, дневник исследователя.

| Параметр | Значение |
|---|---|
| Размер | 1024×1024, бесшовная плитка |
| Формат | WebP, без альфы |
| Тон | Тёплый кремовый в нейтральной середине, волокна и лёгкая неоднородность плотности |
| Имя файла | `paper-parchment.webp` |

### Царапины и потёртости

Накладывается поверх любого корпуса как самостоятельный слой износа.

| Параметр | Значение |
|---|---|
| Размер | 1024×1024 |
| Формат | **PNG с альфой** — по умолчанию полностью прозрачный, царапины серым по альфа-каналу |
| Плотность | Редкая — 6–10 заметных царапин на кадр, не сплошная сетка |
| Имя файла | `wear-scratches.png` |

### Кляксы

Для алхимика и карты проказников — пятна чернил, не общий износ.

| Параметр | Значение |
|---|---|
| Размер | 512×512 |
| Формат | PNG с альфой |
| Тон | Тёмно-серый/чёрный по прозрачному, 3–5 клякс разного размера на кадр |
| Имя файла | `ink-blots.png` |

## Как скин подключает текстуру

```css
.dial-housing {
    background-color: #1c1c1c;                 /* цвет задаёт скин */
    background-image: url('../assets/textures/metal-brushed-radial.webp');
    background-blend-mode: overlay;             /* текстура — только фактура поверх цвета */
}
.dial-housing::after {
    content: "";
    position: absolute; inset: 0;
    background-image: url('../assets/textures/wear-scratches.png');
    opacity: 0.35;                               /* интенсивность износа настраивает скин */
    pointer-events: none;
}
```

## Правило, которое текстура не имеет права нарушать

Из [SKINS.md](../../docs/SKINS.md), правило 5: **текстура — материал, а не данные.** Она не
показывает азимут, время или фазу солнца — это работа SVG-слоя, который пересчитывается
каждую минуту. Если однажды текстуре понадобится нести смысл (например, светящаяся точка износа
как индикатор) — это уже не текстура, а часть отрисовки, и её место в коде скина, а не в этой
папке.
