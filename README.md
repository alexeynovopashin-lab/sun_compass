# Солнечный компас

Минималистичный астрономический инструмент для фотографов: наведите телефон на объект и узнайте,
**когда солнце окажется ровно на этом азимуте** — с датой, временем, высотой над горизонтом и фазой света.

Прибор намеренно скупой: шкала, точка солнца сейчас, точка результата — и всё. Ход солнца за
сутки, зоны золотого и синего часа и таблица их времён спрятаны в **скрытом режиме** и включаются
двойным тапом.

- Версия: **2.0.0**
- Формат: PWA (устанавливается на домашний экран, работает офлайн)
- Публикация: GitHub Pages из ветки `main`
- Репозиторий: <https://github.com/alexeynovopashin-lab/sun_compass>

## Что показывает кольцо

| Элемент | Что означает |
|---|---|
| Белая точка на орбите `r = 115` | Солнце **сейчас** |
| Золотая точка на орбите `r = 140` | Результат замера — куда и когда придёт солнце |
| Риска сверху | Визир: направление, в которое смотрит верхний торец телефона |

Ни траектории, ни засечек, ни подписей. Прибор отвечает на один вопрос и молчит об остальном.

Внизу — строка `↑ 08:24 · Золотой час 4° · ↓ 21:07`: восход, текущая фаза с высотой солнца, заход.
Цвет фазы совпадает с цветом соответствующей зоны в скрытом режиме.

## Скрытый режим

**Двойной тап** по компасу или по кнопке спуска. Пасхалка, не тир функций: включённой её выдаёт
только тихая приписка `SN-01` рядом с номером версии.

На диск ложится ход солнца за сутки в полярной проекции — **угол это азимут, радиус это высота
солнца**:

| Элемент | Что означает |
|---|---|
| Пунктирная окружность `r = 115` | Линия горизонта, высота 0° |
| Центр диска | Зенит, высота 90° |
| Дуга ближе к центру | Солнце выше |
| Дуга за пределами пунктира | Солнце уже под горизонтом, сумерки |
| Толстая яркая часть дуги | То, что ещё **впереди** сегодня |
| Тонкая приглушённая часть | То, что уже **прошло** |

Работает эта проекция прежде всего **ближе к экватору**: там солнце идёт почти через зенит,
за день азимут меняется мало, и на голом кольце сутки сжались бы в короткий штрих. В полярной
проекции тот же день разворачивается во всю ширину диска. В средних широтах разница скромнее —
там азимут и так растянут на полнеба.

Мишень замера в скрытом режиме садится не на внешнюю орбиту, а прямо на дугу — на ту высоту,
которая у солнца будет в найденный момент.

### Легенда зон

В скрытом режиме строка состояния становится ручкой: тап по ней выдвигает снизу таблицу зон дня
с временами — золотой час утром и вечером, восход, день, закат, синий час, ночь. Тап по самой
таблице её убирает.

Времена берутся из событий SunCalc (`sunrise`, `goldenHourEnd`, `goldenHour`, `sunset`, `dusk`),
а не из порогов раскраски: у таблицы своя логика — золотой час начинается от видимого восхода
(−0.833°), тогда как дуга красится от 0°. Расхождение — считаные минуты.

### Цвета и пороги

Пороги высоты солнца — единый источник правды для дуги, подписи результата и строки состояния
(`SUN_PHASES` в `index.html`):

| Высота солнца | Фаза | Цвет |
|---|---|---|
| ≥ +6° | День | белый, тонкая нить |
| 0° … +6° | Золотой час | `#ffd25f` → `#ff9a3c` |
| −0.833° … 0° | Восход / Закат | `#ff6b35` |
| −6° … −0.833° | Синий час | `#4d7fd6` |
| −12° … −6° | Навигационные сумерки | `#2a3f7a` |
| −18° … −12° | Астрономические сумерки | тёмно-синий |
| < −18° | Ночь | не рисуется |

−0.833° — стандартный порог видимого захода с поправкой на рефракцию и угловой радиус диска.

## Как пользоваться

1. **Включить компас** — приложение запросит датчики ориентации и геопозицию.
   Если в геолокации отказано, включается демо-режим по координатам Москвы.
2. **Держите телефон горизонтально, экраном вверх**, направив верхний торец на интересующий объект.
3. **Одиночный тап** по кнопке спуска или по компасу — замер. Азимут фиксируется, запускается ролик:
   из центра выстреливает мишень, солнце едет по орбите к цели, одометр докручивает найденное время.
4. **Повторный одиночный тап** — сброс.

Жесты по компасу и по кнопке спуска:

| Жест | Действие |
|---|---|
| Одиночный тап | Замер, повторно — сброс |
| Двойной тап | Скрытый режим: траектория солнца и легенда зон |
| Тройной тап | Zoom: компас увеличивается вдвое и встаёт центром под кнопку спуска |

Если для выбранного направления солнце никогда не поднимается выше −6° (например, строго на север
в средних широтах), приложение показывает «Не освещается», а одометр уходит в хаотичную прокрутку —
намеренная метафора «сломанного механизма». Сброс — тапом.

## Устройство проекта

```
index.html      всё приложение: встроенный SunCalc, стили, разметка и логика
sw.js           service worker, офлайн-режим
manifest.json   PWA-манифест
icon.svg        исходная иконка
icon-192.png    иконка для домашнего экрана iOS
icon-512.png    иконка для установки и maskable-варианта
docs/           архитектура, changelog, план порта на Swift
```

Приложение сознательно остаётся **одним HTML-файлом без сборки и зависимостей**: открывается мгновенно,
правится в любом редакторе, не требует npm. Логика внутри `index.html` разбита на именованные секции
(`==== Траектория солнца ====`, `==== Одометр ====` и т. д.), которые один в один ложатся на будущие
Swift-файлы — см. [docs/SWIFT_PORT.md](docs/SWIFT_PORT.md).

Подробности алгоритмов — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
История версий — в [docs/CHANGELOG.md](docs/CHANGELOG.md).

## Локальный запуск

`file://` не годится: Service Worker и манифест требуют http(s). Поднимите локальный сервер:

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

и откройте <http://127.0.0.1:8765/index.html>.

На десктопе датчиков ориентации нет, поэтому компас будет смотреть на север, а геолокация браузера
может отдать отказ — это нормально, приложение перейдёт в демо-режим.

## Точность и ограничения

- Астрономия — SunCalc 2.0.1 (MIT), встроен в `index.html` без минификации.
  Погрешность по положению солнца — доли углового градуса, чего с запасом хватает для съёмки.
- Поиск времени решает **обратную задачу**: по азимуту находит момент. Грубое сканирование года
  с шагом в час, затем бинарный поиск в 20 итераций внутри найденного часа (точность ~3 мс).
  Худший случай (солнце никогда не приходит на этот азимут) — около 10 мс.
- Прохождения ниже −6° отбрасываются: свет уже не работает на кадр. Константа `SEARCH_MIN_ALTITUDE`.
- Время выводится в часовом поясе устройства. Пока вы физически находитесь в точке замера,
  это верно; в демо-режиме по координатам Москвы время будет показано по вашему поясу.
- Компас опирается на `webkitCompassHeading` (iOS) или `alpha` с поправкой на поворот экрана.
  Точность магнитометра телефона — единицы градусов; рядом с металлом и магнитами больше.
- Приложение считает, что телефон держат горизонтально: наклон не компенсируется.

## Приватность

Координаты не покидают устройство. Единственный внешний запрос — обратное геокодирование
названия города через `photon.komoot.io`, результат кэшируется в `localStorage` с округлением
координат до 0.1°. Без сети приложение работает полностью, просто вместо названия города
показываются координаты.
