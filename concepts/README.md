# Концепты

Дизайн-макеты будущих скинов. Живой код — в `../skins/`, здесь только идеи.

| Файл | Что это |
|---|---|
| `sn-01.html` | Исходный концепт прибора SN-01: корпус, утопленный циферблат, светлые барабаны счётчика, алюминиевая кнопка. Лёг в основу `skins/braun.html` |
| `glitch.html` | Терминальная оболочка с пятью темами — AMB, GRN, CYN, MON и аркадная GLG. Загрузочный экран, эффект кинескопа, глитч при переключении |

## Данные в макетах ненастоящие

`glitch.html` на любой азимут отвечает `18:42` — время захардкожено, обратной задачи внутри нет.
Это нормально для макета и недопустимо в скине.

**Концепт переезжает в `skins/` только когда подключён к движку**: SunCalc, геолокация, курс
с поправками, поиск прохождения. Правила, которые скин обязан соблюдать, — в
[../docs/SKINS.md](../docs/SKINS.md).

## Как смотреть

Через `file://` работать не будет — нужен http:

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Дальше <http://127.0.0.1:8765/concepts/glitch.html>.
